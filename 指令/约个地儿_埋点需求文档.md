## 一、埋点命名规范

### 1.1 通用规则

| 规则 | 说明 |
|:---|:---|
| **全英文小写** | 所有字段、事件名都用小写英文 |
| **下划线连接** | `_` 分隔单词，禁止驼峰 / 中划线 |
| **三段式结构** | `一级页面_二级页面/模块_动作`，最多 4 段 |
| **页面层级一致** | 一级页面名与代码 pages 目录名对齐 |

### 1.2 动作命名

| 中文 | 英文 | 用途 |
|:---|:---|:---|
| 展示 | `show` | 元素曝光（页面、卡片、弹窗、面板） |
| 点击 | `click` | 用户主动点击 |
| 关闭 | `close` | 关闭弹窗 / 面板 / 页面 |
| 成功 | `success` | 业务操作成功（创建、加入、添加完成等） |
| 失败 | `fail` | 业务操作失败 |
| 输入 | `input` | 表单输入完成（blur 触发） |
| 确认 | `confirm` | 表单提交 / 弹窗确认 |

### 1.3 一级页面命名

| 页面 | 英文标识 |
|:---|:---|
| 首页 | `index` |
| 加入页（被邀请人页） | `join` |
| 地图页 | `map` |

### 1.4 二级模块命名（地图页）

| 模块 | 英文标识 |
|:---|:---|
| 地图主视图 | `mapview` |
| 顶部状态栏 | `topbar` |
| 右侧工具栏 | `toolbox` |
| 添加好友面板 | `addpanel` |
| 推荐地点面板 | `recommend` |
| 地点详情面板 | `place` |
| 用户详情面板 | `userpanel` |
| 碰头地点浮卡 | `meetcard` |

### 1.5 命名示例

```
✅ 正确
index_launch_click           // 首页 - 发起按钮 - 点击
map_addpanel_invite_click    // 地图页 - 添加面板 - 邀请按钮 - 点击
join_authorize_success       // 加入页 - 授权 - 成功

❌ 错误
indexLaunchClick             // 驼峰
首页-发起-点击                // 中文
home-click                   // 缺少层级
```

## 二、公共字段（所有事件必带）

| 字段名 | 类型 | 含义 | 取值说明 |
|:---|:---|:---|:---|
| `event_name` | string | 事件名 | 如 `index_launch_click` |
| `event_time` | int64 | 客户端事件时间戳 | 毫秒 |
| `user_id` | string | 用户唯一标识 | 服务端注册返回的 user_id |
| `openid` | string | 微信 openid | 用户唯一标识，可能为空（未登录） |
| `session_id` | string | 会话 ID | 每次启动小程序生成一个 UUID |
| `app_version` | string | 小程序版本号 | 如 `1.0.3` |
| `system_info` | string | 系统信息 | iOS_14.0 / Android_12 |
| `model` | string | 设备型号 | iPhone14,2 |
| `network_type` | string | 网络类型 | wifi / 4g / 5g / unknown |
| `scene` | int | 进入场景值 | 微信场景值，如 1001（首页）、1007（分享卡片） |
| `referer` | string | 来源页 | 上一页 path，如 `pages/index/index` |
| `meeting_id` | string | 当前碰头 ID | 进入碰头后必带，未进入则为空 |
| `is_creator` | int | 是否发起人 | 1=是 / 0=否 / -1=无碰头 |

## 三、首页（index）埋点

### 3.1 页面级

#### `index_show`
- **上报时机**：首页 onShow 触发时（包括首次进入和返回）
- **业务字段**：

| 字段名 | 类型 | 含义 | 取值说明 |
|:---|:---|:---|:---|
| `is_first_visit` | int | 是否首次进入 | 1=是 / 0=否（看本地存储） |
| `has_avatar` | int | 是否已设置头像 | 1=是 / 0=否 |
| `has_nickname` | int | 是否已设置昵称 | 1=是 / 0=否 |
| `has_active_meeting` | int | 是否有进行中的碰头 | 1=是 / 0=否 |
| `enter_scene` | int | 进入场景 | 1001=主入口、1007=分享卡片、1011=扫码、1023=扫一扫 |

---

### 3.2 产品特性卡片（首次进入展示）

#### `index_feature_show`
- **上报时机**：未授权用户进入首页，产品特性卡片展示时
- **业务字段**：无（仅记录曝光）

---

### 3.3 我的信息卡片

#### `index_profile_show`
- **上报时机**：已授权用户「我的信息」卡片展示时

#### `index_profile_avatar_click`
- **上报时机**：用户点击头像编辑按钮（chooseAvatar 触发）

| 字段名 | 类型 | 含义 | 取值说明 |
|:---|:---|:---|:---|
| `from_state` | string | 触发时的授权状态 | `no_avatar` / `has_avatar` |

#### `index_profile_avatar_success`
- **上报时机**：头像选择成功（拿到 avatarUrl）

| 字段名 | 类型 | 含义 | 取值说明 |
|:---|:---|:---|:---|
| `is_default_avatar` | int | 是否使用默认头像 | 1=是 / 0=否 |

#### `index_profile_nickname_input`
- **上报时机**：昵称输入框 blur 时（昵称非空才上报）

| 字段名 | 类型 | 含义 | 取值说明 |
|:---|:---|:---|:---|
| `nickname_length` | int | 昵称字符数 | 整数，不上报昵称内容（隐私） |

### 3.4 发起碰头按钮

#### `index_launch_click`
- **上报时机**：用户点击底部「发起碰头」按钮

| 字段名 | 类型 | 含义 | 取值说明 |
|:---|:---|:---|:---|
| `btn_state` | string | 按钮当前状态 | `no_avatar`=未授权 / `no_nickname`=有头像无昵称 / `ready`=都有 |

#### `index_launch_success`
- **上报时机**：碰头创建成功，跳转到地图页前

| 字段名 | 类型 | 含义 | 取值说明 |
|:---|:---|:---|:---|
| `meeting_id` | string | 新创建的碰头 ID | 服务端返回 |
| `cost_ms` | int | 创建耗时 | 从点击按钮到收到成功响应的毫秒 |

#### `index_launch_fail`
- **上报时机**：碰头创建失败

| 字段名 | 类型 | 含义 | 取值说明 |
|:---|:---|:---|:---|
| `error_code` | string | 错误码 | 网络错误 `network`、服务端 `server`、未知 `unknown` |
| `error_msg` | string | 错误信息 | 具体报错文本（不超过 200 字） |

| 字段名 | 类型 | 含义 | 取值说明 |
|:---|:---|:---|:---|
| `meeting_id` | string | 碰头 ID | |
| `total_member_count` | int | 加入后总成员数 | |
| `cost_ms` | int | 加入耗时 | |

#### `join_fail`
- **上报时机**：加入失败

| 字段名 | 类型 | 含义 | 取值说明 |

| `error_msg` | string | 错误描述 | |

### 7.1 核心漏斗

#### 漏斗 A：发起人转化（首次访问 → 完成发起）

```
3. join_authorize_success        授权完成
4. join_success                  加入成功
5. map_show (enter_from=join)    进入地图
```

#### 漏斗 C：邀请裂变

```
3. map_share_appmsg_show         分享面板触发
4. map_share_appmsg_success      分享成功
   ↓
（被邀请人）
5. join_show (referer=share)     加入页打开

```


## 八、上报方式 & 技术约定

### 8.1 上报渠道
- **客户端**：使用 `wx.reportEvent` 上报到微信数据分析（如果有定制化分析平台，则走自有 SDK）
- **统一接口**：封装为 `tracker.track(eventName, params)`
- **批量上报**：每 5 秒或攒满 20 条触发一次 flush，进入后台立即 flush

### 8.2 数据隐私
- 不上报昵称内容、不上报头像 URL
- 经纬度仅在「manual_friend / 长按选点」场景上报，精度 6 位小数
- 错误堆栈截断 1000 字符
- 涉及用户身份的字段使用 user_id 而非 openid（除非业务必须）

### 8.3 字段类型规范
- string 字段最大长度 200 字符
- 时间戳统一使用毫秒
- 距离使用米（int）
- 耗时使用毫秒（int）
- 布尔值统一用 int（0/1），不用 true/false 字符串

### 8.4 兜底
- 如果用户未登录，`user_id` 字段填 `anonymous_${session_id}`
- 如果在拦截到的事件中字段缺失，必填字段填 `unknown`
