# 碰面 MeetPoint - 微信小程序

> 🎯 基于多人实时位置和驾车路线，智能推荐全局最优碰面地点

## 功能介绍

**碰面**是一款帮助多人聚会时快速找到最佳碰面地点的微信小程序。发起人创建碰面活动后，通过微信分享链接邀请好友加入，小程序实时追踪所有参与者位置，结合驾车路线规划，推荐公平合理的碰面地点。

### 核心特性

- 📱 **实时位置追踪** — 每 3 秒自动更新参与者位置，微信头像标注
- 👤 **手动添加好友** — 为未安装小程序的朋友标记固定位置
- 🧮 **智能推荐算法** — 球面几何中心 + 驾车路线规划
- 🗺️ **地图可视化** — 实时展示所有人位置、碰面地点、驾车路线
- 🏷️ **6 种场所类型** — 美食、公园、咖啡店、地铁站、商场、商业圈
- 📌 **图面点选** — 点击地图任意位置查看 POI 详情并设为碰面地点
- 🚗 **多路线展示** — 同时展示所有成员到碰面地点的驾车路线和时长
- 🧭 **三方导航** — 腾讯地图 / 高德地图 / 百度地图 深度链接
- 🔗 **微信分享** — 小程序卡片分享，点击直接加入碰面

### 约束规则

- 每人同时只能发起/加入 **1 个碰面活动**
- 每个碰面活动最多 **20 人**
- 主态（创建者）和客态（加入者）角色区分

## 使用流程

```
主态流程：
1. 首页设置头像和昵称 → 点击"发起碰面"
2. 进入地图页，自动定位 → 实时显示位置
3. 点击"+"分享小程序卡片给好友
4. 可手动添加离线好友的位置
5. 选择场所类型 → 智能推荐碰面地点
6. 或直接在地图上点选任意位置设为碰面地点
7. 查看所有人的驾车路线 → 一键导航出发

客态流程：
1. 收到分享卡片 → 点击进入加入页
2. 确认碰面信息 → 加入碰面
3. 自动进入地图页，参与位置共享
```

## 核心算法

### 球面几何中心（Geographic Midpoint）

将所有参与者的 GPS 坐标转换为三维笛卡尔坐标，取平均值后转回经纬度：

```
1. 经纬度 → 弧度
2. 转换到三维：x = cos(lat)·cos(lng), y = cos(lat)·sin(lng), z = sin(lat)
3. 取所有点的平均值：x̄, ȳ, z̄
4. 转回经纬度：center_lng = atan2(ȳ, x̄), center_lat = atan2(z̄, √(x̄²+ȳ²))
```

### 驾车路线规划

集成腾讯地图驾车路线 API，计算每位成员到候选碰面地点的：
- 驾车距离（公里）
- 预计时长（分钟）
- 路线轨迹（polyline 渲染在地图上）

### 碰面区域计算

1. 计算所有人的球面几何中心
2. 搜索半径 = max(800m, min(最远距离 × 0.6, 10000m))
3. 在中心点附近搜索指定类型 POI，按距离排序

## 开发配置

### 前置条件

1. [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 注册微信小程序账号，获取 AppID
3. 申请 [腾讯位置服务 Key](https://lbs.qq.com/)

### 配置步骤

1. 打开微信开发者工具，导入本项目
2. 修改 `project.config.json` 中的 `appid` 为你的 AppID
3. 修改 `app.js` 中的 `mapKey` 为你的腾讯地图 API Key
4. 在微信公众平台「开发管理 → 开发设置」中添加服务器域名：
   - request 合法域名：`https://apis.map.qq.com`

### 权限配置

小程序需要以下权限（已在 app.json 中声明）：
- `scope.userLocation` — 获取用户地理位置
- `requiredPrivateInfos: ["getLocation"]` — 隐私接口声明

> ⚠️ 自 2022 年起，`wx.getLocation` 需要在微信公众平台申请隐私接口权限

## 技术要点

| 技术点 | 实现方案 |
|--------|----------|
| 地图展示 | 微信小程序 `<map>` 组件（GCJ-02 坐标系） |
| 位置获取 | `wx.getLocation` API（每 3 秒轮询） |
| 头像获取 | `open-type="chooseAvatar"`（2024+ 新规范） |
| POI 搜索 | 腾讯地图 WebService API `/ws/place/v1/search` |
| POI 详情 | 腾讯地图 Place Detail API `/ws/place/v1/detail` |
| 驾车路线 | 腾讯地图 `/ws/direction/v1/driving/` + polyline 解压 |
| 逆地理编码 | 腾讯地图 `/ws/geocoder/v1/` |
| 导航 | 腾讯/高德/百度地图 URL Scheme 深度链接 |
| 碰面管理 | 本地 `wx.Storage`（可扩展为云开发） |
| 数据同步 | 轮询机制（3 秒间隔，可升级为 WebSocket） |
| 分享 | `onShareAppMessage` 小程序卡片分享 |

## 扩展建议

- **云开发升级**：将本地 Storage 替换为微信云开发数据库，实现真正的多端实时同步
- **WebSocket 通信**：替代轮询，实现低延迟的实时位置同步
- **AI 推荐**：接入大模型，根据用户偏好和历史记录智能推荐
- **历史记录**：保存碰面历史，方便下次复用
- **评论系统**：碰面结束后可对地点评价
